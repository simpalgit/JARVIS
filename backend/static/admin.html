LOGIN

Account token

Login token sirf account page ke liye hai. Inbox, phone, aur overview isi computer par token ke bina chalte hain. Yeh API internet par open nahi hai.

GET /Backend zinda hai ya nahi. Jawab mein assistant ka naam aur mode aata hai.
POST /messageDesk aur voice. Body: {"text":"Aaj ke messages batao"}. Jawab {"reply":"..."}.
GET /api/admin/overviewDashboard, inbox, contacts, aur settings. Yeh page har 3 second par yahi maangta hai.
POST /api/inboxMessage log karo. Body mein channel, sender, aur body hota hai. Gmail ya WhatsApp khud se nahi aata.
POST /api/inbox/{id}/sendApprove. Emergency stop on ho to reply nahi jaata.
POST /api/inbox/{id}/skipReject. Us message ka reply nahi banta.
POST /api/contactsNaam jodo. role business ho to reply list, operational ho to skip.
POST /api/controlReply mode approval, auto, ya both. Saath mein emergency_stop true ya false.
POST /api/account/loginAdmin login. Body: email aur password. Token wapas aata hai.
